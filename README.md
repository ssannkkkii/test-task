# Test Task for Recruiter Inforce

This repository contains a test task for a recruitment process at Inforce, showcasing both the frontend and backend implementations.

## Project Overview

This project consists of:

- **Frontend**: Built with TypeScript, React, and SCSS. It allows users to interact with a sneaker store interface, manage sneakers (add, display, delete), and sort products based on various criteria.
  
- **Backend**: Powered by Python and Django REST Framework. The backend handles product data, API interactions, and business logic.

## Features

- **Frontend**:
  - Display a list of sneakers fetched from the backend API.
  - Add new sneakers through a form with validation.
  - Delete sneakers with a confirmation prompt.
  - Sort sneakers alphabetically, by quantity, price, and availability.
  
- **Backend**:
  - Exposes REST API endpoints for managing sneaker data.
  - Handles CRUD operations for sneakers.
  - Manages sneaker data stored in a PostgreSQL database.
